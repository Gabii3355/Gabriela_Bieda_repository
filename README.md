## Python

The `python` directory contains exercises and projects related to:

- basic Python syntax
- object-oriented and advanced programming
- simple applications
- small games
- university programming assignments

To run a selected Python script:

```bash
cd python/project_name
python3 script_name.py
```

## HTML

The `html` directory contains exercises and small websites created during classes.

The projects include examples such as:

- a portfolio website
- a business card website
- unit converters
- forms and user-input exercises
- simple interactive web pages

To open an HTML project:

```bash
cd html/project_name
firefox index.html
```

You can also open the `index.html` file directly in a web browser.
